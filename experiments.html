MathML

Einstein's formula for mass-energy equivalence, written with MathML:

E = m c 2

Here E is energy, m is mass, and c is the speed of light.

MathML couldn't be used by developers because there are browsers out there that were unable to support it. On caniuse.com, Chrome 4-23 and 25-96 cannot enable this feature at all. Edge 12-96 and Safari iOS 3.2-4.3 also doesn't allow this feature. If many of the browsers would show this feature as broken, it would be risky to use MathML. Therefore, javascript libraries would be used instead. However, MathML support has been added recently in Chrome browsers as the feature became easier to implement.
